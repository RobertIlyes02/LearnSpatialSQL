Detect Invalid Geometries

Easy Data Quality ST_IsValidST_MakeValid

Solve this in your browser →

A spatial database has been populated from multiple sources and some geometries are malformed — self-intersecting polygons, bowtie shapes, and so on. Before running any analysis you need to flag the bad rows and check whether they can be repaired automatically.

Goal

Return the feature_id of every geometry that fails the validity check, plus a fixable column: true if ST_MakeValid produces a valid geometry from it. Order by feature_id.

Example Output

feature_id  fixable
----------  -------
2           true
4           true

Table: features

ColumnTypeDescription
feature_idINTEGERPrimary key
geomGEOMETRYGeometry to validate

ST_IsValid(geom) returns TRUE/FALSE. ST_MakeValid(geom) attempts to repair an invalid geometry — re-checking the result with ST_IsValid tells you if the repair succeeded.

Hints

💡 Hint 1 Filter with WHERE NOT ST_IsValid(geom) to keep only the invalid rows.
💡 Hint 2 ST_IsValid(ST_MakeValid(geom)) — repair, then re-validate — gives you the fixable flag in one expression.
