NYC Taxi Pickup Hotspots

Medium Geocoding read_parquetST_PointFLOOR

Solve this in your browser →

You have a sample of 2,000 NYC taxi trips stored in a Parquet file. Each row has a pickup latitude and longitude.

Goal

Bin pickups into a 0.01° grid (roughly 1 km cells) and return the top 5 cells by pickup count.

Use FLOOR(col / 0.01) * 0.01 to snap each coordinate to the nearest grid corner, and ROUND(..., 2) to clean up floating-point noise.

Expected Output

grid_lat  grid_lon  pickups
--------  --------  -------
40.75    -73.98     129
40.75    -73.99     126
40.72    -74.0      122
40.76    -73.98     95
40.72    -74.01     91

Parquet file: ./data/nyc_taxi_sample.parquet

ColumnTypeDescription
pickup_latDOUBLEPickup latitude
pickup_lonDOUBLEPickup longitude
dropoff_latDOUBLEDropoff latitude
dropoff_lonDOUBLEDropoff longitude
trip_distance_kmDOUBLEEuclidean trip distance
fare_usdDOUBLEFare amount
passenger_countINTEGERNumber of passengers
pickup_hourINTEGERHour of pickup (0–23)

Hints

💡 Hint 1 Read the file directly in your query: FROM read_parquet('./data/nyc_taxi_sample.parquet') — no setup needed.
💡 Hint 2 ROUND(FLOOR(pickup_lat / 0.01) * 0.01, 2) snaps latitude to the grid and removes floating-point noise in one step.
💡 Hint 3 GROUP BY both grid columns, then ORDER BY COUNT(*) DESC LIMIT 5.
