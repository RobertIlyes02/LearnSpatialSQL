Compass Bearings Between Hubs

Hard Measurement ST_AzimuthJOIN

Solve this in your browser →

Flight planners quote routes by compass bearing. Compute the initial bearing between every pair of airport hubs.

Goal

Self-join the hubs table to form each unordered pair exactly once (use a.code < b.code), and return the bearing from A to B in degrees.

Return from_ap, to_ap, bearing_deg (rounded to 1 decimal place), ordered by from_ap, to_ap.

Expected Output

from_ap  to_ap  bearing_deg
-------  -----  -----------
JFK      LAX    261.5
JFK      MIA    203.7
JFK      SEA    278.0
LAX      MIA    102.1
LAX      SEA    343.9
MIA      SEA    297.3

Table: hubs

ColumnTypeDescription
codeVARCHARIATA airport code
geomGEOMETRYAirport point (lon, lat)

ST_Azimuth(a, b) returns the bearing from point a to point b in radians, measured clockwise from north. DuckDB's degrees() converts radians to degrees.

Hints

💡 Hint 1 A self-join with ON a.code < b.code generates each pair once (JFK–LAX but not LAX–JFK) with no self-pairs.
💡 Hint 2 ST_Azimuth returns radians — wrap it: ROUND(degrees(ST_Azimuth(a.geom, b.geom)), 1).
💡 Hint 3 Sanity check: LAX is west of JFK, so JFK→LAX should be roughly 260° (west-southwest), not 80°.
