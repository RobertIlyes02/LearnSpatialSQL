Nearest Neighbor Search

Easy Distance ST_DistanceORDER BY

Solve this in your browser →

Given a table of coffee shops and a table of users, find the 5 nearest coffee shops to user with id = 1, sorted by distance ascending (break ties alphabetically by shop name).

Goal

Return shop_name and dist_km (distance in kilometres, rounded to 2 decimal places), ordered nearest-first.

Example Output

shop_name       dist_km
--------------  -------
Brew & Co.      0.31
The Daily Grind 0.87
...

Tables

ColumnTypeDescription
users.idINTEGERUser ID
users.lat / lngDOUBLEUser location
shops.shop_idINTEGERShop ID
shops.shop_nameVARCHARShop name
shops.geomGEOMETRYPoint (EPSG:4326)

ST_Distance in DuckDB spatial returns degrees by default for geographic coordinates. Multiply by ~111.195 to convert to kilometres.

Hints

💡 Hint 1 Use a cross join (JOIN … ON TRUE) to compare one user against all shops.
💡 Hint 2 ST_Distance(ST_Point(lng, lat), shops.geom) * 111.195 gives approximate km.
