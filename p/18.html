H3 Hexbin Hotspots

Hard H3 Grid h3_latlng_to_cellH3read_parquet

Solve this in your browser →

Rectangular grids distort area away from the equator — that's why ride-share companies aggregate into H3 hexagons instead. Re-analyze the NYC taxi pickups from a Parquet file using H3 cells.

Goal

Assign each pickup to its H3 cell at resolution 7 (~1.2 km hexagons), and return the top 5 cells by pickup count as hex strings.

⚠️ This problem needs the H3 community extension: INSTALL h3 FROM community; LOAD h3; (already in the starter code).

Expected Output

h3_cell          pickups
---------------  -------
872a100d6ffffff  455
872a1072cffffff  445
872a100d2ffffff  286
872a100d8ffffff  238
872a10728ffffff  148

Parquet file: ./data/nyc_taxi_sample.parquet

ColumnTypeDescription
pickup_latDOUBLEPickup latitude
pickup_lonDOUBLEPickup longitude
(other columns omitted — see Problem 21)

h3_latlng_to_cell(lat, lng, resolution) returns the cell as a UINT64. h3_h3_to_string(cell) converts it to the familiar 15-character hex form.

Hints

💡 Hint 1 Argument order matters: h3_latlng_to_cell(pickup_lat, pickup_lon, 7) — latitude first, unlike ST_Point.
💡 Hint 2 Wrap with h3_h3_to_string(...) to get the hex string, then GROUP BY it.
💡 Hint 3 Order by pickups DESC, h3_cell for a deterministic top 5.
