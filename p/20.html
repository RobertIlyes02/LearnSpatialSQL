Load a Parquet Layer

Easy I/O read_parquetGROUP BY

Solve this in your browser →

Real GIS work starts with loading data. DuckDB can query a Parquet file directly — no import step, no CREATE TABLE. This is the gentlest introduction to the file-based problems.

Goal

Query the NYC points-of-interest Parquet file and count how many POIs exist in each category.

Return category and n, ordered by n descending, then category alphabetically.

Expected Output

category    n
----------  --
restaurant  32
museum      5
hotel       3
park        3

Parquet file: ./data/nyc_pois.parquet

ColumnTypeDescription
poi_idINTEGERRow ID
nameVARCHARVenue name
categoryVARCHAR'hotel' | 'museum' | 'park' | 'restaurant'
lat / lonDOUBLEWGS84 coordinates

read_parquet('path') works anywhere a table name can appear — FROM, joins, subqueries. DuckDB reads only the columns your query touches.

Hints

💡 Hint 1 FROM read_parquet('./data/nyc_pois.parquet') — the file path replaces a table name.
💡 Hint 2 A plain GROUP BY category with COUNT(*) finishes the job. Remember the two-level ORDER BY for deterministic output.
