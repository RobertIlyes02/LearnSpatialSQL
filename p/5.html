Route Length from WKT

Easy Measurement ST_LengthST_GeomFromText

Solve this in your browser →

A table of delivery routes stores each path as a WKT LINESTRING. Compute the total length of each route.

Goal

Return route_name and length_units (the raw planar length DuckDB computes — no unit conversion needed for this problem), ordered by length_units descending.

Example Output

route_name   length_units
-----------  ------------
Route C      20.0
Route A      10.0
Route B      7.071068

Table: routes

ColumnTypeDescription
route_idINTEGERPrimary key
route_nameVARCHARRoute label
wktVARCHARRaw WKT LINESTRING text

Use ST_GeomFromText(wkt) to parse the WKT string into a GEOMETRY, then ST_Length(geom).

Hints

💡 Hint 1 You'll need to convert the WKT text to GEOMETRY before measuring it.
💡 Hint 2 ST_Length sums the Euclidean distance between consecutive vertices of the LineString.
