Bounding Box Filter

Easy Indexing ST_EnvelopeST_Intersects

Solve this in your browser →

You have a table of worldwide airports as points. Return all airports that fall inside the bounding box of Western Europe: longitudes -10° to 20°, latitudes 35° to 60°.

Goal

Return iata_code and airport_name, ordered by iata_code.

Example Output

iata_code  airport_name
---------  ----------------------
CDG        Charles de Gaulle
FRA        Frankfurt Airport
LHR        Heathrow Airport

Table: airports

ColumnTypeDescription
iata_codeVARCHAR3-letter IATA code
airport_nameVARCHARFull name
geomGEOMETRYPoint (lng, lat)

Tip: create the bounding box with ST_MakeEnvelope(xmin, ymin, xmax, ymax) and test with ST_Intersects.

Hints

💡 Hint 1 ST_MakeEnvelope(-10, 35, 20, 60) creates the bounding box polygon.
💡 Hint 2 You can also use ST_X(geom) BETWEEN -10 AND 20 AND ST_Y(geom) BETWEEN 35 AND 60.
