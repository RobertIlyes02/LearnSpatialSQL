Spatial Window Function

Hard Analytics PARTITION BYST_WithinRANK

Solve this in your browser →

A retail chain has store locations (points, with annual revenue) and district boundaries (polygons). Management wants the top 2 stores by revenue in each district.

Goal

Spatially assign each store to its district with ST_Within, rank stores by revenue within each district using a window function, and return only ranks 1–2.

Return district_name, store_name, revenue, rnk, ordered by district_name, then rnk.

Expected Output

district_name  store_name   revenue  rnk
-------------  -----------  -------  ---
Downtown       Beta Shop    340000   1
Downtown       Gamma Store  210000   2
Uptown         Delta Mart   500000   1
Uptown         Zeta Corner  430000   2

Tables

ColumnTypeDescription
districts.district_nameVARCHARDistrict label
districts.geomGEOMETRYDistrict polygon
stores.store_nameVARCHARStore label
stores.geomGEOMETRYStore point
stores.revenueINTEGERAnnual revenue

Window functions like RANK() OVER (PARTITION BY ... ORDER BY ...) compute per-group rankings without collapsing rows. DuckDB's QUALIFY clause filters on a window result directly — no subquery needed.

Hints

💡 Hint 1 First get each store's district: JOIN districts d ON ST_Within(s.geom, d.geom).
💡 Hint 2 RANK() OVER (PARTITION BY district_name ORDER BY revenue DESC) ranks within each district.
💡 Hint 3 DuckDB's QUALIFY clause filters on a window expression without a subquery: QUALIFY RANK() OVER (...) <= 2. (Referencing the SELECT alias in QUALIFY needs a newer DuckDB than the browser runtime — repeat the full expression.)
