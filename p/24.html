Rush Hour Fare Analysis

Easy Analytics read_parquetGROUP BYAVG

Solve this in your browser →

City planners want to know when taxi demand peaks. The NYC taxi Parquet file tags every trip with its pickup_hour (0–23).

Goal

Find the 3 busiest pickup hours. For each, return the trip count and the average fare.

Return pickup_hour, trips, and avg_fare (rounded to 2 decimal places), ordered by trips descending, ties broken by pickup_hour ascending.

Expected Output

pickup_hour  trips  avg_fare
-----------  -----  --------
18           218    4.49
22           214    4.65
20           209    4.46

Parquet file: ./data/nyc_taxi_sample.parquet

ColumnTypeDescription
pickup_hourINTEGERHour of pickup (0–23)
fare_usdDOUBLEFare amount
(other columns omitted — see Problem 21)

Hints

💡 Hint 1 This is pure SQL aggregation — no spatial functions needed. GROUP BY pickup_hour.
💡 Hint 2 ROUND(AVG(fare_usd), 2) for the fare; ORDER BY trips DESC, pickup_hour keeps ties deterministic.
