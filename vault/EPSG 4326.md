# EPSG:4326 — WGS84

The coordinate reference system used throughout GeoSQL problems.

- **X axis:** longitude, −180 to +180
- **Y axis:** latitude, −90 to +90
- **Units:** degrees
- **Common name:** WGS84, "lat/lon"

## Distance in degrees
At mid-latitudes (~45°), 1° ≈ 78 km longitude, 111 km latitude. Near the equator, 1° ≈ 111 km in both axes. Use these rough conversions for buffer distances:

| Distance | Approx degrees |
|----------|---------------|
| 100 m | 0.001° |
| 500 m | 0.005° |
| 1 km | 0.009° |
| 10 km | 0.09° |
